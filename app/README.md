# ALIRIN App

Frontend React untuk ALIRIN, aplikasi peta risiko dan pelaporan drainase mikro.

## Scripts

```bash
npm run dev                 # server pengembangan
npm run lint                # eslint
npm run test                # vitest
npm run build               # build produksi

npm run supabase:seed-auth  # buat/perbarui akun admin & petugas (butuh service role key)
npm run supabase:check      # cek hak akses Supabase per peran: warga, admin, petugas
```
